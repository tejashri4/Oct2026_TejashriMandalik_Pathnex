##Ansible - set up vpc peeoirng between aws accounts

```yaml
- name: Setup VPC Peering Between Accounts
  hosts: localhost
  tasks:
     - name: Create VPC peering connection
       command: aws ec2 create-vpc-peering-connection --vpc-id  vpc-12345678 --peer-vpc-id vpc-87654231
